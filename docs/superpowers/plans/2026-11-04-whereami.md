# Whereami Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for this small change.

**Goal:** Add the approved support-oriented `/whereami` chat block.

**Architecture:** A Velocity SimpleCommand renders a single localized component
through the existing system renderer. The command uses the current invoker's
backend and proxy-specific environment data; no external lookup is needed.

**Tech Stack:** Kotlin, Velocity, Adventure, library-i18n, JUnit, Gradle.

**Spec:** `docs/superpowers/specs/2026-11-04-whereami-design.md`

## Constraints and review focus

No permission grant, no local-proxy assumption about other players, no cached
backend, no duplicate system prefix. Console has no location. Missing data must
not become a copy action. Preserve full IDs and treat all values as literal text.
Use existing colors and pack readiness behavior in all four supported locales.
